# Tkinter To-Do List App

A lightweight desktop application built with Python and the Tkinter library for managing daily tasks.

## Features
- **Add Tasks:** Quickly add items via the input field or by pressing 'Enter'.
- **Duplicate Prevention:** Notifies you if a task already exists in the list.
- **Task Counter:** Real-time tracking of total tasks.
- **Manage Tasks:** Delete individual tasks or clear the entire list with a single click.
- **Scrollable Interface:** Easily navigate through long lists of tasks.
